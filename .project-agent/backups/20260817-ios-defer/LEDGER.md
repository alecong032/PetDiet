## 📝 使用说明

本台账由 `project-ledger` Skill 自动管理。

**字段说明**:
- **验收标准**: 任务完成的可验证条件（必须可量化）
- **输入**: 任务开始所需的前置条件、资源、文档
- **输出**: 任务完成后产生的交付物（代码、文档、配置等）
- **依赖**: 必须先完成的任务 ID（支持多个，用逗号分隔）
- **工时**: 预计完成时间（人时），用于进度估算

**更新规则**:
1. 任务开始时：状态 `⬜` → `🟡`，记录开始日期
2. 任务完成时：状态 `🟡` → `✅`，记录完成日期，更新输出
3. 任务阻塞时：状态 → `🔴`，备注中说明原因
4. 任务跳过时：状态 → `⏭️`，备注中说明原因
5. 每次更新后同步阶段进度和统计摘要
