## 一、注册与开通步骤

### 1.1 注册腾讯云账号

**步骤**:

1. 访问 [腾讯云官网](https://cloud.tencent.com/)
2. 点击右上角「免费注册」
3. 使用企业/团队邮箱注册（确保账号归属清晰）
4. 完成实名认证（个人或企业均可）
   - 个人认证：身份证信息
   - 企业认证：营业执照等

> ⚠️ **注意**: 企业认证后续更灵活，支持团队协作和权限管理。

### 1.2 开通云开发服务

**步骤**:

1. 登录腾讯云控制台
2. 搜索「云开发」或访问 [CloudBase 控制台](https://console.cloud.tencent.com/tcb)
3. 点击「新建环境」
4. 填写环境信息：
   - **环境名称**: `PetDiet-Dev`（开发环境）
   - **计费模式**: 选择「按量付费」（MVP 阶段免费额度足够）
   - **地域**: 选择离目标用户最近的地域
     - 上海 (ap-shanghai) — 华东用户
     - 广州 (ap-guangzhou) — 华南用户
     - 北京 (ap-beijing) — 华北用户
5. 确认开通，等待环境创建（约 1-3 分钟）

> ⚠️ **重要**: 地域一旦选定不可更改！

### 1.3 获取环境 ID

开通成功后，在云开发控制台首页可以看到：

- **环境名称**: PetDiet-Dev
- **环境 ID**: 格式如 `petdiet-xxxxx`（记录此 ID）

## 二、创建子账号与权限配置

### 2.1 为什么必须使用子账号？

| 原因 | 说明 |
|------|------|
| **安全风险** | 主账号密钥权限过大，泄露后可操作所有云资源 |
| **权限隔离** | 子账号仅授予云开发相关权限，最小权限原则 |
| **审计追踪** | 可追踪每个子账号的操作记录 |
| **团队协作** | 方便后续团队成员加入 |

### 2.2 创建子账号步骤

1. 访问 [访问管理 - 用户列表](https://console.cloud.tencent.com/cam)
2. 点击「新建用户」→ 选择「自定义创建」
3. 填写用户信息：
   - **用户名**: `petdiet-dev`
   - **访问方式**: 编程访问（用于 API 调用）
4. 设置权限：
   - 搜索「云开发」
   - 选择策略：`QcloudCloudBaseFullAccess`（云开发全读写权限）
   - 或自定义策略仅授予必要的读写权限
5. 完成创建，**立即保存** SecretId 和 SecretKey

> 🔐 **安全提醒**: SecretKey 只在创建时显示一次，请立即保存到安全位置！

## 三、获取并配置密钥

### 3.1 获取密钥

**主账号密钥**（不推荐用于开发）:
1. 访问 [访问管理 - API 密钥](https://console.cloud.tencent.com/cam/capi)
2. 查看 SecretId 和 SecretKey

**子账号密钥**（推荐）:
1. 在子账号创建成功页面直接获取
2. 或在 [用户列表](https://console.cloud.tencent.com/cam) 点击子账号 → API 密钥

### 3.2 配置环境变量

在项目根目录创建 `.env.local` 文件：

```bash
# 腾讯云开发配置
TENCENT_CLOUD_ENV_ID=your-env-id-here
TENCENT_CLOUD_SECRET_ID=YOUR_SECRET_ID
TENCENT_CLOUD_SECRET_KEY=YOUR_SECRET_KEY
TENCENT_CLOUD_REGION=ap-shanghai
```

> ⚠️ **安全警告**: 
> - `.env.local` 文件必须在 `.gitignore` 中
> - 不要将真实密钥提交到 Git
> - 文档中使用占位符，不要出现真实密钥

## 七、常见问题

### Q1: 如何切换地域？

**答**: 地域在创建环境时选定，一旦选定不可更改。如需更换地域，需要：
1. 创建新环境（新地域）
2. 迁移数据（导出 → 导入）
3. 更新项目配置

### Q2: 免费额度用完会怎样？

**答**: 
- 按量付费模式：超出部分按实际用量计费
- 系统会通过邮件和控制台发送告警通知
- 可设置预算告警，防止意外费用

### Q3: 主账号和子账号密钥有什么区别？

**答**:
| 对比项 | 主账号密钥 | 子账号密钥 |
|--------|----------|----------|
| 权限范围 | 所有云资源 | 仅授权的服务 |
| 安全风险 | 高（泄露影响大） | 低（权限隔离） |
| 适用场景 | 企业管理员 | 开发/运维人员 |
