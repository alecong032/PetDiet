入口导航归属
  • 顶层 Tab 宿主第一个 destination：app/home（navigation-scheme.md §一 / 路由表）
  • 顶层 Tab 根页不显示返回箭头；系统返回 = 退出到桌面（navigation-scheme §二）
  • 首次使用流（onboarding）完成后清栈进入本页
B宠物形象与当前状态
  • 形象：水豚 6 状态（D-009），图片来自 docs/design/pet-states/；喂食动画期间为 EATING（T2.7/T2.8 动画件）
  • 状态按今日摄入比例 + 属性映射（satiety-map §4 / D-009）：NORMAL/HAPPY/HUNGRY/EATING/OVERFULL/SICK
  • 状态文案与宠物昵称占位；昵称命名属 P5 增强（T5.6），MVP 可显示默认名或不显示（待 T2.6.1 定）
C3 属性（饱食度 / 健康值 / 心情值）
  • 数值范围 0-100，来自 PRD §3.1；展示为进度条 + 数值
  • 饱食度与卡路里目标联动：今日摄入比例 → 饱食度（PRD §3.2）；健康值为长期指标，心情值由前两者衍生
  • 进度条颜色/语义色待 T2.6.1 高保真定稿（本线框仅示意占位）
D今日摄入 vs 目标
  • 今日累计摄入（kcal）对照 CalorieGoal.dailyCalorieGoal（PRD §5.1）
  • 比例驱动饱食度五区间（satiety-map §2），喂食闭环结束后回本页即时刷新（navigation-scheme §四）
  • 数值联动规则详见 core-flow.html Lane 04
E主按钮「拍照喂食」
  • 首页内容区显著主按钮，非中央 FAB（navigation-scheme §五：避免被误认为第 5 个 Tab）
  • 点击 push 全屏二级流程 flow/capture（拍照 / 选图 → 识别 → 确认 → 喂食 → 反馈 → 回首页）
  • 只在首页放拍照入口，其他 Tab 不重复（navigation-scheme §五一致性）
F底部导航（仅顶层 Tab 根页显示）

  • 图标 + 文字同显；二级流程页与弹层隐藏 NavigationBar（navigation-scheme §七）
注范围边界
