区域说明与依据

入口导航归属
  • 顶层 Tab 宿主第 3 个 destination：app/stats（navigation-scheme §一）；Tab 根页无返回箭头

  • 「新增体重记录」push weight/record?source=stats，保存后返回本页并刷新趋势（navigation-scheme §六路径 C）
统计日 / 周摄入统计
  • 日视图：今日累计摄入 vs CalorieGoal.dailyCalorieGoal（PRD §5.1）；数值口径与首页一致（1,240 / 2,000 = 62%）
  • 营养素（蛋白质 / 碳水 / 脂肪）字段来自 FoodRecord 营养字段（PRD §5.1 / T3.13.2 手动输入口径）；具体克数为占位示意
  • 周视图：按周汇总 / 趋势（T2.3.4 验收「日/周统计」；详细图表规格待 T5.3.2 / T2.6.4 细化）
  • 营养均衡评估可反哺宠物健康值（core-flow Lane 04），本页仅展示数据
体重体重趋势
  • 体重记录 = WeightRecord（weight / recordedAt，PRD §5.1）；曲线由历史序列渲染（F7 体重趋势图）
  • 可对照目标体重（T5.8 目标体重设置，P5 增量；本线框标注为设计衔接）
  • 录入入口三处共用同一页面：统计页按钮 / 喂食反馈轻提醒（CR-001）/ 设置页提醒间隔（navigation-scheme §六）
注范围边界
