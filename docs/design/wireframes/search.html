区域说明与依据

入口导航归属
  • 顶层 Tab 宿主第 2 个 destination：app/search，参数 [mode]：browse / recognitionFallback（navigation-scheme 路由表）
  • Tab 根页无返回箭头；非首页 Tab 根按系统返回 → 回到首页 / 宠物 Tab（navigation-scheme §二返回规则）
  • mode=recognitionFallback 由 AI 识别失败 / 低置信度降级进入（navigation-scheme §四）
  • 选中食物后 push flow/food-confirm/{draftId}：复用既有确认食物页，不新增失败页面（navigation-scheme §四降级说明）
搜索搜索与列表
  • 模糊搜索返回 Top-10（T5.1.1 搜索 API，P5 增量期实现）；MVP 期搜索数据来源待定，低置信度 / 识别失败时以降级手填兜底（core-flow Lane 02 / Lane 03）
  • 列表项：缩略图 / 食物名 / 每份热量 / 收藏星标；分量为默认 1 份，进入确认页后可按 stepper 调整（feeding.html S3）
  • 示例条目与 capture.html 候选一致（红烧肉饭 650 / 卤肉饭 / 咖喱鸡饭）；「白米饭」为额外占位项；热量均为占位示意（食物数据集 T5.4，P5）
收藏收藏入口
  • 星标可切换收藏（PRD S2 常见食物收藏 · MVP 增强项）；「收藏」段展示已收藏食物用于快捷录入（T5.2 收藏 API，P5）
  • 收藏为 MVP 增强项（Should Have）；本线框仅规划其位置与交互形态
兜底手动输入
  • 搜索本身即 AI 识别失败时的降级方案（PRD S1 手动搜索食物）
  • 搜索无结果时提供手动输入食物名 + 热量 + 营养素（core-flow Lane 03「无候选 / 识别为空」）
  • 识别置信度 <0.70 时的手动输入兜底属 core-flow Lane 02（置信度分级分支），与本页降级入口互补
  • 手动录入条目同样进入确认食物页 → 喂食闭环
注范围边界
  • 本线框为 MVP 搜索 Tab 主状态；空态（无收藏 / 无历史）与键盘交互由 T2.6.6 高保真与实现细化
  • 示例食物与热量均为自洽占位示意，非真实食物库数据
