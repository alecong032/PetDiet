区域说明与依据

S3确认食物页
  • 展示 AI 候选确认后的食物详情：菜名、分量、热量可修正（core-flow Lane 01「确认食物」）
  • 从识别候选或搜索结果选中后 push（navigation-scheme 路由表），返回 = 来源页
  • 「喂食宠物」主按钮 → push flow/feeding/{draftId}；离开未确认用确认对话框保护（navigation-scheme §七）
  • 热量/分量示例为自洽占位示意（T2.3.2 识别页不承载热量编辑，在此页完成）
S4喂食动画页
  • 保存摄入并播放进食动画 1.5–2s（T2.7.2 / T2.8.2 动画规格）；动画期间状态 = EATING（D-009）
  • 写入 FoodRecord 后由 PetEngine 计算新属性（TDD §6.2）；完成后进入反馈屏
  • 动画/数值/轻提醒均为当前页状态更新，不新增 destination（navigation-scheme §四边界）
S5宠物反馈页
  • 展示新状态 + 反馈文案 + 属性变化；文案随 6 状态（D-009，core-flow Lane 04 反馈表）
  • 示例：摄入 94%（ratio 0.945）→ 满足区间（satiety-map §2：hunger 70–90），mood → 90 → HAPPY（D-009 优先级 mood ≥ 70）；健康 +3 按营养中性计（nutritionHealth=0），实际叠加 TDD §6.2.2 营养评估
  • 体重轻提醒 CR-001：距上次记录超间隔（默认 7 天）同页非打断式提示，点击 push weight/record?source=feedback，忽略继续
  • 「返回首页」清除本次流程栈并刷新首页累计摄入与宠物状态（navigation-scheme §四）
