区域说明与依据

入口导航归属
  • 首页主按钮 push flow/capture；完成后全屏 push flow/recognition/{sessionId}（navigation-scheme 路由表）
  • 二级流程页：隐藏底部导航、顶部显示返回箭头；识别页返回 = 拍照 / 选图（navigation-scheme §二返回规则）
  • 候选选择为弹层 dialog/food-candidates/{sessionId}，不新增业务页面（navigation-scheme 边界说明）
S1拍照 / 选图页
  • 相机预览（CameraX）+ 快门 + 相册入口；支持重拍 / 重新选择（core-flow Lane 01）
  • 图片预处理压缩 ≤5MB（默认 <1MB）、EXIF 矫正（TDD §4.1 / T3.10.3 口径）
  • 相机权限首次需授权说明；取消返回首页（core-flow Lane 03 异常：中途取消不产生记录）
S2识别结果页
  • 展示 Top-3 候选 + 置信度；AI 请求 P95 < 3s（TDD §4.1），热量/分量在确认食物页调整（T2.3.3）
  • 置信度分级（TDD §2.2/§3.2）：>0.90 自动确认（跳过候选）；0.70–0.90 弹层选择；<0.70 提示手动输入
  • 本屏示例为 0.70–0.90 分支（候选列表 + 弹层），84/76/71% 为自洽示意值（均落在候选区间）
  • 「搜索/手动输入」为识别失败/低置信度降级入口，复用搜索收藏页（navigation-scheme §四）
异常错误与降级
  • AI 失败/超时：3s 超时自动重试 1 次 → 提示 → 手动输入（TDD §4.3，core-flow Lane 03）
  • 限流：指数退避 1s/2s/4s；空结果：引导手动输入（TDD §4.3）
  • 弱网/离线：本地暂存图片，恢复后补识别（TDD §7.2）
  • 示例数值（84/76/71% 等）为自洽占位示意，非真实识别结果
注范围边界
  • 本线框覆盖拍照页 + 识别结果页两屏；确认食物 / 喂食 / 反馈页见 T2.3.3
  • 亮 / 暗模式、相机具体控件样式待 T2.6.2 高保真定稿
