区域说明与依据

入口导航归属
  • 顶层 Tab 宿主第 4 个 destination：app/settings（navigation-scheme §一）；Tab 根页无返回箭头
  • 支持 app/settings?section=weightReminder 直接定位到体重提醒间隔区，不新建子页面（navigation-scheme §六路径 B 边界）
  • 非首页 Tab 根系统返回 → 回首页 / 宠物 Tab（navigation-scheme §二）
A个人资料（F5）
  • 字段：性别 / 年龄 / 身高 / 体重 / 活动量，均为 BMR、TDEE 计算输入（PRD F5 / §2.4）
  • 资料修改后目标随最新资料重算，旧目标失效前提示确认（goal-flow Lane 04）
  • 校验：必填 + 数值合理范围，失败提示修正不保存（goal-flow Lane 04）
  • 资料编辑为同页内联编辑 / 弹层 dialog（dialog/confirm 系），不新增 destination；行尾 ✎ 表示可编辑，非跳转
B目标设置（F6）
  • 目标类型三选一：减重 TDEE−500 / 维持 TDEE / 增重 TDEE+300（PRD §2.4）
  • 每日卡路里目标支持自动计算或手动覆盖（F6）；CalorieGoal 记录 targetWeight / goalType / dailyCalorieGoal / bmr / tdee / isAutoCalculated（PRD §5.1）
  • 目标与宠物联动：今日摄入比例驱动饱食度与状态（core-flow Lane 04）
  • 本页示例（目标 2,000 kcal / 目标体重 60.2 kg）为占位示意；BMR / TDEE 实际数值不在此页展开，计算链见 goal-flow.html
C体重记录与提醒（F7 / CR-001）
  • 「新增体重记录」push weight/record?source=settings；保存后返回本页（navigation-scheme §六）
  • 提醒间隔默认 7 天、可调（CR-001）；超间隔时在喂食反馈页同页非打断式提醒（feeding.html S5）
  • 三处录入入口共用同一页面：统计页按钮 / 反馈轻提醒 / 本页按钮（navigation-scheme §六「既有第三入口」）
注范围边界
  • 本线框为 MVP 设置 Tab 主状态；无资料 / 未设目标的首次状态由 onboarding 承接（首次使用流后不会再回到空态）
  • 「账号与登录」属首次使用流 onboarding/auth（MVP Must，F5）；设置页内的账号管理入口与「关于」均为版式占位，无路由、不计入 P2 交付
  • 示例数值（60.2 kg / 2,000 kcal / 目标体重 60.2 kg）为自洽占位示意：维持档 = 保持当前体重，60.2 kg 与 stats.html 体重序列末点一致
