PetDiet Color System

颜色系统规范 · T2.5.1 · 基于既有自然绿色品牌色，覆盖 Material 3 亮色/暗色主题与 WCAG 2.x AA 对比度要求。

一、设计原则

自然与陪伴

沿用水豚与自然主题的绿色系，表达健康、平和与长期陪伴感，不另起品牌主色。

清晰优先

正文至少 4.5:1；大字至少 3:1；可感知的控件边界与状态指示至少 3:1。

语义稳定

成功、警告、错误、信息在亮暗主题中含义不变；颜色随主题调整，不改变信息等级。

不只靠颜色

状态必须同时配合图标、文字或形状；错误提示还需关联字段说明，兼顾色觉差异用户。

继承关系：#4F7D4A、#385A35、#B8D8B2、#F7FBF4、#263324、#6F7D6C、#DCE8D9 均直接继承自 T1.5.2。新增颜色只补足交互、语义和暗色主题。

七、WCAG AA 对比度验证

可复算方法：先将 8-bit sRGB 通道归一化为 c = value / 255；若 c ≤ 0.04045，则 C = c / 12.92，否则 C = ((c + 0.055) / 1.055)^2.4。相对亮度 L = 0.2126R + 0.7152G + 0.0722B；对比度 (L较亮 + 0.05) / (L较暗 + 0.05)。

阈值：普通文字 ≥ 4.5:1；大字（≥18pt，或 ≥14pt 加粗）≥ 3:1；需要被感知的 UI 组件边界/状态图形 ≥ 3:1。比值四舍五入到两位小数。

九、使用规则

  • 主色：用于核心路径、当前选中和品牌识别。同屏只保留一个最高强调的实心主操作。
  • 辅助色：只用于食物、餐食、喂养相关点缀；不能用暖橙替代“警告”，警告必须调用语义 token。
  • 语义色：成功、警告、错误、信息不可互换，也不可直接把高饱和颜色大面积铺底；优先采用“深色内容 + 浅色容器”。
  • 文本：正文使用 onSurface；次级小字使用新的 #687665。既有 #6F7D6C 在白底只有 4.35:1，不作普通尺寸正文。
  • 边界：#DCE8D9 只作装饰分割。输入框、开关轮廓等若靠边界识别，使用 outline。
  • 色盲友好：状态标签同时显示图标和文字；图表使用线型、点型或直接标注；表单错误包含字段名和修复建议，禁止只把边框变红。
  • 暗色模式：不简单反相；背景使用深绿黑，表面略提亮，前景色降低饱和度并提高明度。系统跟随 Android Material 3 主题，用户选择可覆盖系统设置。
