04　全局数据与宠物状态联动

由目标系统和每次喂食共同更新，结果回显到首页与反馈页

联动数据链 · F3 / F4 / F6

每日目标 + 今日累计摄入 → 摄入比例

摄入比例更新饱食度；摄入量与营养均衡度更新健康值；两者共同派生心情值与宠物视觉状态。

影响页面：首页 / 宠物页、喂食、宠物反馈、统计 / 体重页、设置 / 资料页。

视觉状态枚举 · F4

😊happy目标附近
😢hungry摄入 < 60%
😋eating喂食动画中
🤢overfull摄入 > 120%
🤒sick健康值 < 30
