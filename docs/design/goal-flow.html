01　目标设置主链 · BMR/TDEE 计算

首次使用（注册后建档）或「设置 → 个人资料」修改后进入（PRD §2.4 / §5.3）

F5 · Must

入口

  • 首次建档（注册后）
  • 或设置页修改资料
F5 · Must

填写资料

  • 性别 / 年龄
  • 身高 / 体重
  • 活动量（5 档）
校验

表单校验

  • 必填 + 数值范围
  • 失败 → 提示修正（Lane 04）
§2.4

计算 BMR

  • Mifflin-St Jeor
  • 男：10×kg + 6.25×cm − 5×岁 + 5
  • 女：10×kg + 6.25×cm − 5×岁 − 161
§2.4

计算 TDEE

  • TDEE = BMR × 活动系数
  • 久坐 1.2 / 轻度 1.375
  • 中度 1.55 / 高度 1.725 / 极高 1.9
F6 · Must

选择目标类型

  • 减重 / 维持 / 增重
  • 可设定目标体重
F6 · Must

生成每日卡路里目标

  • 自动计算或手动覆盖
  • 保存 CalorieGoal
  • 存 BMR / TDEE 供展示
F6 · Must

宠物联动生效

  • 今日摄入 vs 目标
  • 驱动饱食度 / 状态
  • ⇢ 衔接喂食闭环

目标计算完整口径见 PRD §2.4；目标生成后进入日常使用（拍照→识别→喂食，见 docs/design/core-flow.html）。

02　目标档位与宠物联动规则

每日卡路里目标 = 基础目标 + 目标类型调整（PRD §2.4 / F6）

目标类型每日卡路里目标说明宠物联动（摄入 vs 目标）
减重（lose）TDEE − 500 kcal约每周减 0.5kg≈ 目标（90%–110%）→ 满足；≥ 110% → 过饱/吃撑（健康值↓，>120% 加重）；< 60% → 饥饿（饱食度↓）；60%–90% → 正常。完整五区间见 core-flow Lane 04
维持（maintain）TDEE保持当前体重
增重（gain）TDEE + 300 kcal温和增重

手动设置目标时仍保留 BMR / TDEE 展示并标记 isAutoCalculated=false；CalorieGoal 同步记录 targetWeight / goalType / bmr / tdee / dailyCalorieGoal（PRD §5.2 数据模型）。

03　体重记录长期闭环

体重变化反哺 BMR 计算，维持目标与现实同步（F7）

F7 · Must

定期称重录入

  • 记录体重 kg
  • 记录时间 recordedAt
  • 触发：喂食后轻提醒（CR-001）
  • 间隔默认 7 天，设置页可调，非打断式
F7 · Must

保存体重记录

  • 追加 WeightRecord
  • 形成历史序列
F7 · Must

趋势图查看

  • 体重变化曲线（PRD F7）
  • 对照目标体重（设计衔接）
设计衔接

体重反哺目标

  • 资料体重同步更新
  • BMR / 目标按新体重重算
  • ↩ 回到 Lane 01 计算链

前 3 步主体为 PRD F7 / WeightRecord 明确范围；「体重反哺目标（自动重算）」与趋势图「对照目标体重」为设计衔接建议，落地前需与 PRD §2.4 口径核对（Android 端计算规格待 TDD 补充后再对齐）。

04　异常与边界

所有异常路径不产生无效目标、不丢已保存数据

校验失败

提示修正，不保存

  • 必填项缺失
  • 数值超出合理范围
  • 修正后重新校验
中途退出

丢弃未保存修改

  • 不写入资料 / 目标
  • 已保存的历史不变
  • ↩ 返回原页面
手动覆盖目标

允许但不静默

  • 可手动输入每日目标
  • 标记 isAutoCalculated=false
  • 仍展示 BMR / TDEE 参考值
修改资料后

目标随最新资料重算

  • 身高 / 体重 / 活动量变化
  • → 重算 BMR / TDEE
  • 旧目标失效前提示确认

范围说明：自动/手动设置与目标体重来自 PRD F6；「提示确认」「保留 BMR / TDEE 参考展示」等细则为设计衔接建议，落地前与 TDD 实现口径对齐。
