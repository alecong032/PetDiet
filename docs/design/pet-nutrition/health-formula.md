# 健康值（health）计算公式

> 参数来源：TDD §6.2.4。该参数表是本文所有模型参数的单一声明源；计算顺序参见 TDD §6.2.2 第 4～6 步及 §6.2.3。

## 1. 输入定义

| 输入 | 含义 | 单位或范围 |
|---|---|---|
| `current_health` | 计算前的健康值 | 0～100 |
| `food.calories` | 本次食物热量 | kcal |
| `food.protein` | 本次食物蛋白质 | g |
| `food.carbs` | 本次食物碳水化合物 | g |
| `food.fat` | 本次食物脂肪 | g |
| `ratio` | 今日累计摄入 / 每日卡路里目标，来自 T2.4.1 | 无量纲 |
| `Δt` | 当前时间与 `lastCalculatedAt` 的间隔，仅用于 App 回前台衰减 | 小时 |

喂食计算与 App 回前台衰减是 TDD §6.2.3 中的两个独立计算入口。喂食时执行公式 A、B、C；App 回前台时根据由 `ratio` 映射出的 `hunger` 执行时间衰减，不重复计算本次食物的摄入量或营养增量。

## 2. 公式 A：摄入量评估 `intake_health`

参数来源：TDD §6.2.4。

```text
intake_health =
  -2, ratio < 0.60
   0, 0.60 <= ratio < 0.90
  +3, 0.90 <= ratio <= 1.10
  -1, 1.10 < ratio <= 1.20
  -4, ratio > 1.20
```

边界归属：`ratio = 1.10` 时为 `+3`；`ratio = 1.20` 时为 `-1`。

## 3. 公式 B：营养均衡评估 `nutrition_health`

参数来源：TDD §6.2.4。

先按食物热量计算三种营养素的热量占比：

```text
proteinRatio = (food.protein * 4) / food.calories
fatRatio     = (food.fat * 9) / food.calories
carbRatio    = (food.carbs * 4) / food.calories
```

再按以下顺序判定：

> ⚠️ 除零防护（TDD §6.2.3 `evaluateNutrition` guard）：若 `food.calories = 0`（异常数据），不进行占比计算，直接返回 `nutrition_health = 0`。

```text
nutrition_health =
  +2, proteinRatio >= 0.15 且 fatRatio <= 0.35
  -3, fatRatio > 0.40
      或 (proteinRatio < 0.05 且 carbRatio > 0.70)
   0, 其余情况
```

判定顺序与 TDD §6.2.2、§6.2.3 一致：先判断 `+2` 条件，再判断 `-3` 条件。

## 4. 公式 C：健康值更新

参数来源：TDD §6.2.4。

```text
new_health = clamp(current_health + intake_health + nutrition_health, 0, 100)

clamp(x, 0, 100) = max(0, min(x, 100))
```

因此健康值计算结果不会小于 0，也不会大于 100。

## 5. 时间衰减（App 回前台）

参数来源：TDD §6.2.4。`hunger` 由 App 回前台时的 `ratio` 按 T2.4.1 映射重新计算；时间惩罚不会改变 `hunger`。

```text
若 hunger < 20 且 Δt >= 6h：
  health_penalty = min(5, (Δt - 6) * 0.5)

否则若 hunger > 95 且 Δt >= 4h：
  health_penalty = min(3, (Δt - 4) * 0.5)

否则：
  health_penalty = 0

new_health = max(0, current_health - health_penalty)
```

这里 `0.5` 的单位为每小时；长期饥饿惩罚上限为 5，长期过饱惩罚上限为 3。阈值采用严格的 `hunger < 20` 和 `hunger > 95`，因此恰好等于 20 或 95 时不触发。

## 6. 单元测试用例表

下表中的食物和初始状态数值仅为测试输入，不是新增模型参数。营养占比保留精确分数或有限小数参与判定。喂食用例的 `Δt` 不参与计算；回前台用例不执行公式 A、B，故食物及相应输出记为“不适用”。

| 用例名 | 输入（`current_health`、`food`、`ratio`、`Δt`） | 预期 `intake_health` | 预期 `nutrition_health` | 预期衰减 | 预期 `new_health` | 手算过程简述 |
|---|---|---:|---:|---:|---:|---|
| 均衡合理餐 | `50`；`100 kcal, P 5 g, C 10 g, F 3 g`；`1.00`；不适用 | `+3` | `+2` | 不适用 | `55` | 蛋白占比 `5*4/100=0.20`，脂肪占比 `3*9/100=0.27`，满足均衡；`clamp(50+3+2)=55`。 |
| 吃撑惩罚 | `50`；`100 kcal, P 5 g, C 10 g, F 3 g`；`1.21`；不适用 | `-4` | `+2` | 不适用 | `48` | `1.21>1.20`；营养均衡；`clamp(50-4+2)=48`。 |
| 节食 | `50`；`100 kcal, P 2.5 g, C 10 g, F 4 g`；`0.59`；不适用 | `-2` | `0` | 不适用 | `48` | `0.59<0.60`；蛋白占比 `0.10`、脂肪占比 `0.36`，均不满足加分或扣分条件；`clamp(50-2)=48`。 |
| 高脂不均衡 | `50`；`100 kcal, P 5 g, C 5 g, F 5 g`；`1.00`；不适用 | `+3` | `-3` | 不适用 | `50` | 脂肪占比 `5*9/100=0.45>0.40`；`clamp(50+3-3)=50`。 |
| 上限 clamp | `100`；`100 kcal, P 5 g, C 10 g, F 3 g`；`1.00`；不适用 | `+3` | `+2` | 不适用 | `100` | 原始结果 `100+3+2=105`，上限截为 `100`。 |
| 下限 clamp | `0`；`100 kcal, P 5 g, C 5 g, F 5 g`；`1.21`；不适用 | `-4` | `-3` | 不适用 | `0` | 原始结果 `0-4-3=-7`，下限截为 `0`。 |
| 摄入边界 1.10 | `50`；`100 kcal, P 5 g, C 10 g, F 3 g`；`1.10`；不适用 | `+3` | `+2` | 不适用 | `55` | `1.10` 归入合理摄入；`clamp(50+3+2)=55`。 |
| 摄入边界 1.20 | `50`；`100 kcal, P 5 g, C 10 g, F 3 g`；`1.20`；不适用 | `-1` | `+2` | 不适用 | `51` | `1.20` 归入略多；`clamp(50-1+2)=51`。 |
| 长期饥饿衰减触发 | `50`；不适用；`0.30`；`8h` | 不适用 | 不适用 | `1` | `49` | T2.4.1 映射得 `hunger=0.30*50=15<20`；`min(5,(8-6)*0.5)=1`；`max(0,50-1)=49`。 |
| 长期过饱衰减触发 | `50`；不适用；`1.20`；`8h` | 不适用 | 不适用 | `2` | `48` | T2.4.1 映射得 `hunger=100>95`；`min(3,(8-4)*0.5)=2`；`max(0,50-2)=48`。 |
| 时间衰减不触发 | `50`；不适用；`0.40`；`8h` | 不适用 | 不适用 | `0` | `50` | T2.4.1 映射得 `hunger=0.40*50=20`；不满足严格条件 `hunger<20`，健康值不变。 |

## 7. 验收核对

- 公式 A 的五个摄入区间及 `1.10`、`1.20` 边界与 TDD §6.2.4 一致。
- 公式 B 的三项占比、均衡条件、不均衡条件及判定顺序与 TDD §6.2.2、§6.2.3 一致。
- 公式 C 使用 `clamp(0, 100)`，用例覆盖上下限。
- 时间衰减分别覆盖长期饥饿、长期过饱和不触发场景。
